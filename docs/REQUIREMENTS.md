# Jaipur Stonecraft — Website Requirements

## 1. Core Requirements

The website must be:

- Responsive
- Fast
- SEO-friendly
- Accessible
- Easy to navigate
- Visually premium
- Inquiry-focused
- Easy to maintain

---

# 2. Responsive Design

The website must work correctly on:

- Desktop
- Laptop
- Tablet
- Mobile

Mobile is not an afterthought.

Navigation, typography, imagery, forms and CTAs must all be designed for smaller screens.

---

# 3. Performance

The website should prioritize:

- Fast loading
- Optimized images
- Responsive images
- Lazy loading
- Optimized fonts
- Minimal unnecessary JavaScript
- Efficient animations

Large photography and video should not make the website unnecessarily slow.

---

# 4. SEO

Every important page must support:

- Unique page title
- Meta description
- One clear H1
- Proper H2/H3 hierarchy
- SEO-friendly URL
- Image alt text
- Internal linking
- Canonical URL
- Open Graph metadata
- Sitemap
- Robots.txt
- Structured data where appropriate

SEO should feel natural.

Do not keyword-stuff content.

---

# 5. Product Discovery

Visitors must be able to:

- Browse collections
- Browse products
- Browse projects
- Open individual product pages
- Understand what a product is
- See materials
- See dimensions where available
- Understand customization
- Request a quote

Do not build a generic "Add to Cart" ecommerce experience for custom stonework.

---

# 6. Product Information

Product pages should support information such as:

- Product name
- Category
- Description
- Material
- Dimensions
- Craftsmanship details
- Customization options
- Gallery
- Related products
- Related projects
- Inquiry CTA

Only show information that is actually available.

Never invent specifications.

---

# 7. Project Portfolio

The website must support a project/portfolio system.

Projects may be categorized by:

- Residential
- Hospitality
- Temple
- Commercial
- Garden / Landscape
- Memorial / Tribute
- Custom

Each project may contain:

- Project name
- Project type
- Location
- Description
- Images
- Products used
- Materials
- Craftsmanship story

Only publish verified information.

---

# 8. Inquiry System

Users should be able to submit inquiries.

Basic fields:

- Name
- Email
- Phone
- WhatsApp
- Country
- Project type
- Product/category
- Approximate dimensions
- Requirements
- Message
- Optional file upload

The form should be simple.

Do not ask unnecessary questions.

---

# 9. Contact Options

Provide easy access to:

- WhatsApp
- Phone
- Email
- Contact form

WhatsApp should be particularly accessible on mobile.

---

# 10. Trust

The website should communicate:

- Generational craftsmanship
- Jaipur heritage
- Manufacturing capability
- Skilled artisans
- Custom work
- Quality
- Export experience
- International capability
- Professional communication

Do not publish unverified:

- Awards
- Certifications
- Client names
- Guarantees
- Country counts
- Years of company operation
- Testimonials
- Technical capabilities

---

# 11. Content Management

Products, projects, images and major content should be structured so that they can be updated without rebuilding the entire website.

The architecture should allow the website to grow.

---

# 12. Analytics

The website should be ready for:

- Google Analytics
- Google Search Console
- Conversion tracking

Important conversions:

- Quote request
- Contact form submission
- WhatsApp click
- Phone click
- Email click

---

# 13. Accessibility

Use:

- Semantic HTML
- Proper labels
- Keyboard navigation
- Visible focus states
- Accessible forms
- Good contrast
- Descriptive alt text

---

# 14. V1 Exclusions

Do NOT build in V1:

- CAD portal
- BIM portal
- 3D model downloads
- CNC-related features
- Architect login portal
- Client dashboard
- Production tracking
- Interactive project estimator
- Complex CRM
- Online payment system
- Ecommerce checkout
- Advanced sample-box ecommerce

These may be considered in future versions.
