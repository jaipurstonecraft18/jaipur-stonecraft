# Jaipur Stonecraft — Reusable Components

## Global Components

### Header

Contains:

- Logo
- Navigation
- Request a Quote CTA
- Mobile menu

Header should support:

- Transparent hero state
- Light background state
- Dark background state

---

### Footer

Contains:

- Logo
- Short brand description
- Navigation
- Collections
- Contact
- Social links
- Legal links

---

### Container

Maximum width:

1280px

Provides consistent horizontal spacing.

---

### Section

Reusable section wrapper.

Supports:

- Light background
- Dark background
- Standard spacing
- Large spacing

---

# Rules

Components must:

- Be reusable
- Be responsive
- Be accessible
- Follow DESIGN.md
- Avoid unnecessary duplication
- Support appropriate light/dark contexts

Do not create multiple components that solve the same problem.
