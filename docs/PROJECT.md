# Jaipur Stonecraft — Project Definition

## 1. What Are We Building?

Jaipur Stonecraft is a premium website for a Jaipur-based stone craftsmanship and manufacturing business.

The brand is new, but the family behind the business has been working in this craft for generations.

The website will establish Jaipur Stonecraft as a premium, globally oriented stone craftsmanship brand.

The website should feel like a combination of:

- Luxury atelier
- Art gallery
- Architectural studio
- Heritage craftsmanship house

It should NOT feel like:

- A wholesale marketplace
- A generic marble manufacturer
- An IndiaMART-style catalog
- A cheap handicraft website
- A generic ecommerce store

---
